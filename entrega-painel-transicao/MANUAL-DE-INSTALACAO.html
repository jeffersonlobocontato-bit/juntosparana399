Painel da Transição

Manual de instalação, passo a passo

Para quem vai receber o projeto e continuar as melhorias · Novembro de 2026 · Não é preciso saber programar

Em uma frase Você recebe um arquivo zip. Existem três jeitos de usá-lo: instalar no seu computador (Caminho A, o mais completo), trabalhar só pelo Claude no navegador, sem instalar nada (Caminho B), ou editar o mesmo painel online, se você recebeu um link com permissão de edição (Caminho C). Subir o zip no Claude não instala o projeto sozinho.

1. Antes de começar

O que você deve ter recebido

  • O arquivo painel-transicao-para-enviar.zip.
  • Se houver, um arquivo de dados com final .json, que traz tudo o que a pessoa que enviou já preencheu.

O que você precisa ter

  • Um computador com Windows 10 ou 11, Mac ou Linux (para o Caminho A).
  • Um navegador atualizado (Chrome, Edge, Firefox ou Safari).
  • Uma conta no Claude (claude.ai). Para o Claude Code, confira no guia oficial se o seu plano inclui esse recurso.
  • Conexão com a internet para baixar os programas.
  • Cerca de 30 a 40 minutos na primeira vez.

Na dúvida, comece pelo Caminho A. Os caminhos podem ser usados em conjunto.

3. Caminho A · Instalar no computador

1
Extraia o zip

WindowsClique com o botão direito no arquivo painel-transicao-para-enviar.zip e escolha Extrair tudo…, depois Extrair.

MacDê dois cliques no zip. A pasta aparece ao lado dele.

Você deve verUma pasta painel-transicao-para-enviar com COMECE-AQUI.txt e três subpastas: 1-instalador, 2-projeto-completo e 3-seus-dados.
Não rode de dentro do zipSe o Windows abrir o zip como pasta, ainda não está extraído. Use Extrair tudo.
2
Coloque o arquivo de dados (se você recebeu um)

Copie o arquivo .json para a pasta 3-seus-dados. Você vai usá-lo no passo 6.

3
Verifique se o Python está instalado

O instalador é um programa em Python.

WindowsAbra o menu Iniciar, digite cmd e abra o Prompt de Comando. Digite:

py --version

MacAbra o Terminal (aperte Cmd + Espaço, digite Terminal e Enter). Digite:

python3 --version
Você deve verAlgo como Python 3.11.4. Qualquer número 3.7 ou maior serve. Se aparecer isso, pule para o passo 5.
Se aparecer erro ou o Mac pedir para instalar ferramentasVá para o passo 4. No Mac, se abrir uma janela oferecendo as "ferramentas de desenvolvedor", aceite e espere terminar.
4
Instale o Python (só se faltar)
  1. Abra python.org/downloads e baixe a versão mais recente.
  2. WindowsAbra o instalador e, antes de clicar em Install Now, marque a caixa “Add python.exe to PATH”. Sem isso o atalho não funciona.
  3. Conclua a instalação. Feche e abra de novo o Prompt de Comando ou o Terminal e repita o passo 3.
5
Rode o instalador

WindowsAbra a pasta 1-instalador e dê dois cliques em instalar-windows.bat.

Se o Windows mostrar “O Windows protegeu o computador”Clique em Mais informações e depois em Executar assim mesmo. O arquivo é um texto simples que só chama o instalador. Se preferir, abra-o no Bloco de Notas e confira.

MacNo Terminal, entre na pasta do instalador e rode. Dica: digite cd (com espaço no fim), arraste a pasta 1-instalador para a janela do Terminal e aperte Enter. Depois:

python3 instalar-painel-transicao.py --abrir
Você deve verMensagens como Instalado em: …/PainelTransicao e 19 arquivos gravados, seguidas de “Próximos passos”. O painel abre no navegador.
Onde ficaO projeto é instalado na pasta PainelTransicao, dentro da sua pasta pessoal. Para outro local, rode o instalador com --destino "CAMINHO".
6
Traga os dados preenchidos
  1. No painel aberto no navegador, clique na aba Salvar e restaurar.
  2. Em Restaurar de um arquivo, escolha o .json da pasta 3-seus-dados.
Você deve verUma faixa verde: Dados restaurados: … ofícios, … riscos, … autoridades. Confira os números nos quadros acima.
Se aparecer “Erro: …”O arquivo está incompleto ou não é do painel. Peça a quem enviou para exportar de novo, usando Copiar dados, e cole o texto no campo “Ou cole os dados aqui”.

Sem arquivo de dados, o painel abre só com os dados de exemplo.

7
Instale o Claude Code

É o programa que deixa o Claude trabalhar direto nos arquivos do projeto.

  1. Siga o guia oficial: code.claude.com/docs. Ele é a fonte mais atualizada.
  2. Uma forma comum: instale o Node.js (versão LTS, em nodejs.org) e, no terminal, rode:
npm install -g @anthropic-ai/claude-code

Para conferir, rode claude --version. Na primeira vez que abrir o claude, ele pede o login com a sua conta do Claude.

8
Comece a trabalhar com o Claude

No terminal, entre na pasta do projeto e abra o Claude:

cd ~/PainelTransicao
claude

No Windowsuse cd ~\PainelTransicao no PowerShell (o Terminal do Windows 11).

Digite /primeiro-contato e aperte Enter. O Claude lê o projeto, explica o que existe e propõe os próximos passos, sem alterar nada.

Outros comandos prontos/testar roda os testes. /restaurar-dados ajuda a carregar um arquivo de dados.
AutorizaçõesO Claude pede licença antes de alterar arquivos ou rodar comandos. Leia o que ele pretende fazer e só então aprove. Peça uma melhoria por vez.
9
(Opcional) Rode os testes

Os testes simulam o uso do painel e conferem se tudo continua funcionando. Precisa do Node.js. Na pasta do projeto:

npm install
npx playwright install chromium
npm test
Você deve verVárias linhas OK e, no fim, Todas as verificações passaram.

4. Caminho B · Só com o Claude no navegador

Para quem não quer instalar nada. O Claude lê e melhora os arquivos, mas não grava no seu computador: ele devolve o arquivo novo para você salvar.

1
Extraia o zip como no passo 1 do Caminho A.
2
Crie um Projeto

Em claude.ai, crie um Projeto chamado Painel da Transição.

3
Anexe o contexto

Em Conhecimento do projeto, anexe estes arquivos da pasta 2-projeto-completo: CLAUDE.md, TUTORIAL.md, CHECKLIST.md, docs/ESPECIFICACAO.md e docs/AUTORIDADES.md.

Em Instruções do projeto, cole: “Siga o CLAUDE.md. Responda em português do Brasil. Não invente fatos jurídicos nem nomes.”

4
Peça a melhoria

Abra uma conversa dentro do Projeto, anexe painel-transicao.html e descreva o que quer. Exemplo: “Crie a aba Plano dos 100 dias com medida, secretaria, tipo, meta, responsável e prazo.”

5
Salve o arquivo novo

Baixe o HTML que o Claude devolver e salve por cima do antigo, depois de guardar uma cópia da versão anterior (por exemplo painel-transicao-antigo.html). Abra no navegador para conferir.

Limite do Caminho BBanco de dados, login, anexos reais e testes automáticos precisam do Caminho A.

5. Caminho C · Editar o mesmo painel online

Quem enviou o projeto pode compartilhar a página online do painel com permissão de edição. Assim você abre o link no seu Claude e pede mudanças, e a página publicada é atualizada no mesmo endereço.

1
Receba o convite

Quem enviou usa o menu Compartilhar (Share) da própria página e convida o seu e-mail com permissão para editar. Os nomes exatos das opções podem variar conforme o plano. Um link só para visualização não permite editar.

2
Abra o link no claude.ai e peça a mudança

Entre com a conta que recebeu o convite, abra uma conversa no Claude e cole o link, dizendo o que quer mudar. O Claude lê a página, altera e publica a nova versão.

3
Confira e avise

Abra o link, teste a mudança e avise quem enviou. Duas pessoas editando ao mesmo tempo podem sobrepor o trabalho uma da outra: combinem quem edita e quando.

CuidadosAntes de editar, baixe uma cópia do painel (aba Salvar e restaurar, e o arquivo painel-transicao.html). Os dados digitados ficam no navegador de cada pessoa e não mudam quando a página é atualizada. Esse caminho não grava arquivos no seu computador e não roda testes.

6. Como guardar o seu trabalho

O painel salva sozinho neste navegador, mas isso some se você limpar os dados do navegador ou trocar de computador. A cópia segura é o arquivo:

  1. Abra a aba Salvar e restaurar.
  2. Clique em Baixar dados (arquivo JSON). Se o download for bloqueado, use Copiar dados e cole em um arquivo de texto salvo como .json.
  3. Guarde em PainelTransicao/dados/ com um nome como meus-dados-2026-11-05.json. Arquivos que começam com meus- não vão para o Git nem para o instalador.
O que o arquivo não levaO conteúdo dos anexos (só os nomes). Guarde os documentos em uma pasta à parte.

7. Como atualizar uma instalação existente

Se receber um instalador novo, rode-o com --atualizar:

python3 instalar-painel-transicao.py --atualizar
  • É criada uma cópia de segurança da pasta atual (PainelTransicao.backup-DATA).
  • A pasta dados/ nunca é sobrescrita.
  • Arquivos fora de dados/ que você tenha melhorado voltam à versão do instalador. Se isso acontecer, recupere o que precisa na cópia de segurança.

8. Problemas comuns

O que aconteceO que fazer
O .bat abre e fecha logo, ou diz que não achou o PythonInstale o Python marcando “Add python.exe to PATH” (passo 4) e tente de novo.
No Windows, “py” ou “python” abre a Microsoft StoreO Python não está instalado de verdade. Instale pelo site python.org.
“O instalador está corrompido (SHA-256)”O arquivo foi alterado ou o download falhou. Peça o zip de novo e extraia outra vez.
“A pasta já existe”Proteção contra apagar seu trabalho. Use --atualizar (com cópia de segurança) ou --destino para outra pasta.
O painel abre sem as fontes bonitasÉ só a fonte da internet bloqueada. Funciona igual.
Os dados sumiram ao abrir de novoO navegador limpou o armazenamento. Restaure pelo arquivo .json (aba Salvar e restaurar).
O download do JSON não começaUse Copiar dados e cole em um arquivo .json.
claude não é reconhecidoFeche e abra o terminal. Se persistir, refaça o passo 7 pelo guia oficial.
npm test diz que falta o navegadorRode npx playwright install chromium.
O Claude inventou um nome, número ou artigo de leiPeça a fonte. Se não houver, deve ficar [entre colchetes] ou “A definir”.

9. Cuidados com a informação

  • Não coloque no protótipo dados reais de pessoas, documentos sigilosos, senhas ou chaves.
  • Os titulares das secretarias vieram de notícias e não estão conferidos. Confirme no Diário Oficial antes de enviar qualquer ofício.
  • As regras de conflito de interesses e quem assina os ofícios são sugestões. Peça parecer jurídico antes de adotá-las.
  • Se o projeto for para o GitHub, use um repositório privado e separado do site da campanha.
  • Para o sistema real (banco de dados, login), siga o CHECKLIST.md. O banco de dados deve ficar em ambiente separado do site da campanha.

10. Glossário rápido

TerminalJanela onde se digitam comandos. No Windows: Prompt de Comando ou PowerShell. No Mac: Terminal.
Pasta pessoalSua pasta de usuário (C:\Users\seunome no Windows, /Users/seunome no Mac).
Claude CodePrograma que deixa o Claude ler e alterar os arquivos de uma pasta, com a sua autorização.
JSONFormato de arquivo de texto onde o painel guarda os dados.
InstaladorO arquivo instalar-painel-transicao.py, que contém o projeto inteiro.
SupabaseServiço de banco de dados e login da versão real do sistema (ainda não ligado).

  3. Windows: dois cliques em instalar-windows.bat. Mac: python3 instalar-painel-transicao.py --abrir.
